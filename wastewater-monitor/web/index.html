เดิม — Manual

2. อ่านค่า Flow จากเครื่อง
3. จดค่าลงเอกสาร

1. MS1000 / MV110 ส่งสัญญาณ Flow
2. ESP32 ส่งข้อมูลผ่าน Wi‑Fi อัตโนมัติ
3. Supabase เก็บข้อมูล + Dashboard สรุปรายชั่วโมง
4. ระบบแจ้งความผิดปกติ → คนทวนสอบ → ผู้ช่วยตรวจ → หัวหน้าอนุมัติ
